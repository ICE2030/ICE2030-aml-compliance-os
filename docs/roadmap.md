# AML Compliance OS - Roadmap

## Phase 1: Foundation (Current - MVP)
- [x] Monorepo scaffolding (FastAPI + React)
- [x] Core AML modules (onboarding, screening, risk, cases, transactions, audit)
- [x] JWT auth with RBAC (5 roles)
- [x] Immutable audit log with SHA-256 hash chain
- [x] 4 self-reinforcing loops (learning, trust, efficiency, compliance)
- [x] Pattern detection engine
- [x] Assistive AI layer
- [x] Bilingual Arabic/English with RTL
- [x] UN Sanctions live integration
- [x] SAMA/CMA compliance knowledge base
- [x] Deployed to production

- [x] Source registry with regulator tracking

- [x] Crawler/parser pipeline framework
- [x] Change detection service
- [x] Obligation extraction pipeline
- [x] Hybrid retrieval (keyword + vector)
- [x] Control mapping layer
- [x] Extended dashboard (source monitor, change center, review queue)
- [x] Compliance QA with citations
- [x] AI agent scaffolding
- [x] Comprehensive API with OpenAPI docs
